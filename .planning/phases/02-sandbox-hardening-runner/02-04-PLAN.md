<objective>
Prove the DockerSocketRunner against REAL Docker on this cgroup-v2 machine: inspect the launched
container to assert the hardening flags are actually applied, drive each of the three clocks to a real
kill, truncate a giant-output program, round-trip a stdin echo, and assert no labeled container leaks
after teardown. All of it is GUARDED (build tag `//go:build docker` plus a runtime skip when
DOCKER_HOST is unreachable) so `go test ./...` stays green without Docker, and a `make` target runs it.

This is the verification backbone for the whole phase's safety claims. It is the lighter cousin of
the Phase 4 abuse suite (which runs on Linux CI); here it locks the runner's behavior locally where
Docker + cgroup v2 are available.

Purpose: Demonstrate that hardening, clocks, tree-kill, truncation, and no-leak actually hold against Docker.
Output: build-tagged integration tests + a make target.
</objective>
