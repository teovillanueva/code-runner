<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted code (sandbox) → host | The container is the untrusted thing; hardening flags are the wall |
| worker → host docker socket | Root-equivalent; socket mounted ONLY in worker, NEVER into the sandbox |
| sandbox → network | Must be none; no path to Redis/soketi/metadata |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Elevation of Privilege | HostConfig hardening | mitigate | cap-drop ALL + no-new-privileges + seccomp + non-root + read-only, applied unconditionally in one place (Task 2) |
| T-02-09 | Spoofing/Escape | NetworkMode | mitigate | NetworkMode=none on every container — no SSRF, no reaching Redis/soketi/socket (Task 2) |
| T-02-10 | Denial of Service | memory/pids/tmpfs | mitigate | Memory==MemorySwap (no swap), PidsLimit, size-capped tmpfs /tmp (Task 2) |
| T-02-11 | Denial of Service | process tree | mitigate | Kill = ContainerKill + ContainerRemove(force); whole tree dies, no orphans (Task 3) |
| T-02-12 | Tampering | docker socket exposure | mitigate | socket never bind-mounted into the sandbox; sandbox is network=none (Task 2) |
| T-02-13 | Resource leak | container lifecycle | mitigate | sync.Once Cleanup force-removes container on every terminal path; jobId label enables leak detection (Task 3) |
