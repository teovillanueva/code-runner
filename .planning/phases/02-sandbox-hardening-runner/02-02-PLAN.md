<objective>
Build the soketi output publisher: a Go wrapper over `pusher-http-go/v5` that triggers the four
contract events (`stage`, `stdout`, `stderr`, `result`) on `private-run-<jobId>`, with credentials
from env config, chunking each output payload under soketi's ~10KB event-size limit, and stamping a
monotonic per-job sequence number so the client can detect drops/reorder (PITFALLS pitfall 8).

This is output-only and depends on nothing in the runner, so it runs in parallel with the
DockerSocketRunner (plan 02-03) — neither touches the other's files.

Purpose: The worker triggers soketi directly via the Pusher protocol, batched/chunked under the limit.
Output: `internal/publisher` package.
</objective>
