<objective>
Establish the cross-seam trace carrier and the test scaffolding that proves cross-language trace correlation BEFORE either SDK is wired. This is the Wave 0 foundation slice for the MVP: add `traceparent`/`tracestate` to `JobSpec` in the generated wire contract, then create the in-memory-recorder test scaffolds (Go `tracetest.SpanRecorder` round-trip + TS contract assertion) that downstream plans turn GREEN.

Purpose: The hardest cross-cutting risk in this phase is that a W3C `traceparent` written by the TS SDK and extracted by the Go SDK must decode to the same 16-byte `trace_id` over the Redis-carried `JobSpec` (not HTTP). Proving the contract carrier + the extract round-trip first de-risks every later slice.

Output: Schema change + regenerated TS/zod/Go contract (drift-gate green), a Go extract round-trip test, and a TS contract optionality test. The Go test asserts a known TS-format traceparent decodes correctly (the extract helper it calls is implemented in 08-02 — this test is the contract it must satisfy).

This is a locked founder decision, recorded here so the multi-source coverage audit does not flag OBS-05 as a silent drop.
