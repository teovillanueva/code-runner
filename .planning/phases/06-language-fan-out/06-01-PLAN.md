<objective>
Close the ONE generic core gap that blocks every compiled language: the worker run
path does not yet honor `JobSpec.compile`. Add a generic, manifest-argv-driven
**compile stage** to the Runner/Sandbox seam and wire it into the worker run loop,
then prove it with a language-agnostic test. After this plan, adding Rust/R/SQLite is
purely `languages/<lang>/{manifest.json,Dockerfile}` — this is the ONLY core change
permitted in Phase 6.

Purpose: Rust must compile before it runs (LANG-06). The compile step must run inside
the same hardened sandbox (network=none, caps dropped, non-root, writable workspace),
under the same three clocks and tree-kill, with `stage compiling` emitted, and the run
must be gated on compile exit 0. No language identifier may appear in core.

Output: extended `Sandbox` interface + `DockerSocketRunner`/stub implementations,
worker run-path wiring, a generic compile unit test, and pre-created Makefile targets
that Wave-2 language plans will consume.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| submitted source → compiler (rustc) inside sandbox | Untrusted code is compiled; the compiler itself runs untrusted input |
| compile step → host | The compile exec must inherit ALL sandbox hardening (no network, caps dropped, non-root, clocks) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Denial of Service | compile step (compile-bomb / runaway rustc) | mitigate | compile runs under the same wall/CPU clocks + tree-kill as run; ContainerExec is inside the hardened container; verified by clock-governed compile + Kill on expiry |
| T-06-02 | Elevation of Privilege | ContainerExec compile pre-step | mitigate | exec uses sandboxUser (non-root), WorkingDir=/workspace, inherits container network=none + cap-drop ALL + seccomp + no-new-privileges; no new HostConfig grants |
| T-06-03 | Information Disclosure | compiler stderr streamed to client | accept | compiler diagnostics are intended output; no secrets exist in the network=none sandbox |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | this plan adds NO package installs (pure Go core change); no legitimacy gate needed |
</threat_model>
