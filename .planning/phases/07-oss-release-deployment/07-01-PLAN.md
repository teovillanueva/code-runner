Auth (apps/api/src/auth.ts + app.ts):
- All `/v1/*` routes require `Authorization: Bearer <EXECUTOR_API_TOKEN>` (sha256 + timingSafeEqual constant-time compare).
- Missing/invalid token → `401 {"error":"unauthorized"}`.
- `GET /health` is UNAUTHENTICATED → `200 {"status":"ok"}`.

Endpoints (apps/api/src/routes/*.ts):
- `POST /v1/execute` — body `{language, version?, files:[{name,content}], limits?}`. Success → `202 {jobId, channel:"private-run-<jobId>", status:"queued"}` (returns BEFORE the process starts). Unknown language/version or invalid body → `400 {error, details?}`. Queue full (LLEN jobs:queue >= MAX_QUEUE_DEPTH) → `429` (checked AFTER manifest resolution, so invalid requests get 400 not 429).
- `POST /v1/jobs/:id/start` — PUBLISHes ctrl:<id> {type:"start"} → `202 {ok:true}`.
- `POST /v1/jobs/:id/stdin` — body `{chunk:string}`. Rate-limited (frame rate + pending-byte cap) → `429` on overflow; invalid body → `400`. Success → `200 {ok:true}`.
- `POST /v1/jobs/:id/stdin/close` — PUBLISHes ctrl:<id> {type:"stdin_close"} → `200 {ok:true}`.
- `POST /v1/jobs/:id/kill` — PUBLISHes ctrl:<id> {type:"kill"} → `200 {ok:true}`.
- `GET /v1/jobs/:id` — JobStatus or `404 {error}`. JobStatus.state enum: queued | starting | running | done | killed | error.
- `GET /v1/languages` — array of LanguageInfo from manifests (zero hardcoded languages).
- `POST /v1/channel-auth` — OPTIONAL, only registered when ENABLE_CHANNEL_AUTH=true. Body `{socket_id, channel_name}`. Non-private-run channel → `403`. Missing fields → `400`. Success → Pusher auth response `200`.

Output events on `private-run-<jobId>` (packages/contract/src/index.ts events + wire.schema.json $defs):
- `stage` → StageEvent `{phase}` where StagePhase enum = queued | compiling | running.
- `stdout` / `stderr` → `{chunk:string, seq:integer}` (monotonic seq; soketi delivers data JSON-string-encoded).
- `result` → ResultEvent `{exitCode:int|null, signal:string|null, timedOut:bool, idleTimedOut:bool, truncated:bool, durationMs:int}` (required fields).

Start-handshake sequence (stub + execute.ts):
- execute → client subscribes to private-run-<id> → POST /start → worker starts process. Batch (no-stdin) is the degenerate case; warm-up timeout (WORKER_WARMUP_MS) reclaims the slot if /start never arrives.

Manifest model (languages/*/manifest.json):
- Fields: language, version, aliases[], image, entrypoint, compile (array | null), run (array), interactive (bool), defaultLimits{wallTimeMs, idleMs, cpuMs, memoryMb, pids, outputKb}.
- Python: compile=null, run=["python","main.py"]. Rust: compile=["rustc","-O","main.rs","-o","/workspace/prog"], run=["/workspace/prog"]. SQLite: compile=null, run=["sqlite3","-batch",":memory:","-init","main.sql"].
- Loader auto-discovers languages/*/manifest.json at boot; zero language identifiers hardcoded in Go or API.

Channel auth (apps/stub/src/index.ts + channelAuth.ts):
- Pusher private-channel auth = HMAC-SHA256 over "<socket_id>:<channel_name>" signed with SOKETI_APP_SECRET, returned as "<SOKETI_APP_KEY>:<hmac>".
- Upstream app signs with its copy of the secret. Optional /v1/channel-auth helper does this for demos. Secret read from env only, NEVER written to Redis or returned by any endpoint.

Make targets (Makefile): build-images (python+rust+r+sqlite), python-image, e2e, up, down, abuse, test, test-go, contract, contract-check.

Deployment model (PROJECT.md Key Decisions + docs/scaling.md):
- Scaling unit = the worker NODE (long-lived Go process launching sandboxes internally, up to WORKER_MAX_SANDBOXES), NOT a microVM per execution.
- v1 = DockerSocketRunner. v1 upgrade = gVisorRunner (HostConfig.Runtime="runsc", SANDBOX_RUNTIME=runsc env). v2 (deferred) = FlyMachinesRunner (microVM per execution; seconds of create latency + unproven interactive streaming).
- Worker requires native Redis (blocking SUBSCRIBE/BRPOP); Upstash REST is API-only. Autoscale by LLEN jobs:queue; scale-to-zero via fly-autoscaler / KEDA.
