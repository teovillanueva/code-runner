<objective>
Build the `ArtifactStore` seam and its single shipped `S3Store` (minio-go), the worker config surface for S3 + the three env-managed retention TTLs, the boot-time bucket-create-if-absent + lifecycle rule, and the fail-fast ordering-invariant validation. Thread the (possibly nil) store + RunResultTTL onto `worker.Config` (NOT via new `worker.New` params) so plan 04 consumes them without a signature change or a TODO. This is worker-internal and depends only on the Wave-1 contract.

Purpose: Object storage is the mandatory backend for the artifacts feature (D-02/D-04). The interface preserves the swap seam (mirroring Runner/StdinTransport); S3Store provides presigned GET URLs (R7) and provider-side lifecycle cleanup (R15) so code-runner leaks no objects and stays stateless. EnsureLifecycle is self-sufficient — it creates the bucket if absent (so a fresh MinIO/R2/Tigris works with no external `mc mb` step, R14) before setting the lifecycle rule. When S3 env is unset, the worker runs with a nil store — artifact capture disabled, output pull intact (D-04).

Output: New `internal/artifactstore` package (interface + S3 impl + unit test), extended `config.Config` with `Validate()`, two new `worker.Config` fields (Artifacts + RunResultTTL) with the `New`/`NewWithTransport` signatures unchanged, and worker-main wiring that constructs the store (or nil), fails fast on a broken TTL ordering, and sets the worker Config fields.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → object storage | Worker holds S3 write credentials; signs presigned URLs; creates the bucket on first boot |
| env/secrets → S3Store | AWS_*/ARTIFACT_S3_* creds enter only via config; must never be logged |
| presigned URL → public | The returned `url` is unauthenticated; anyone with it can fetch the object until expiry |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Information disclosure | presigned URL longevity | mitigate | URL expiry is env-managed (default 24h, R7); object TTL ≥ URL TTL enforced by Config.Validate() (Task 1) so a live URL never points at a deleted object; URLs carry no bearer token |
| T-09-05 | Information disclosure | S3 credentials in logs | mitigate | s3.go reads creds only via config (never os.Getenv, never logged); worker-boot logs S3 host/bucket but NOT keys — Task 4 acceptance excludes secret logging |
| T-09-06 | Denial of service | aged objects leaking storage | mitigate | EnsureLifecycle sets a provider-side bucket lifecycle expiration on artifacts/ (R15); no per-object deletion code, stays stateless |
| T-09-07 | Tampering | malformed TTL config (URL outlives object) | mitigate | Config.Validate() fails fast at boot when S3ObjectTTL < PresignedURLTTL (R15 ordering invariant) |
| T-09-09 | Elevation of privilege | auto-creating an arbitrary bucket on boot | accept | EnsureLifecycle MakeBucket targets only the operator-supplied BUCKET_NAME with the worker's own creds; the worker already trusts its S3 creds to write objects — creating that one bucket is within the same trust scope and is required for fresh-backend bootstrap (R14) |
| T-09-SC | Tampering | minio-go install (new go dependency) | mitigate | minio-go is a known top-tier package (RESEARCH CLAUDE.md prefers it over aws-sdk-go-v2); see source-audit note — confirm via pkg.go.dev before install. Not [SLOP]. |
