```go
type Manifest struct {
    Aliases       []string         `json:"aliases"`
    Compile       *ManifestCompile `json:"compile"`        // nil for interpreted langs
    DefaultLimits Limits           `json:"defaultLimits"`
    Entrypoint    string           `json:"entrypoint"`
    Image         string           `json:"image"`
    Interactive   bool             `json:"interactive"`
    Language      string           `json:"language"`
    Run           []string         `json:"run"`
    Version       string           `json:"version"`
}
type ManifestCompile []string

type Limits struct {
    CpuMs, IdleMs, MemoryMb, OutputKb, Pids, WallTimeMs int
}
type LimitsOverride struct {
    CpuMs, IdleMs, MemoryMb, OutputKb, Pids, WallTimeMs *int // nil = no override
}
```

NOTE: go-jsonschema generated PLAIN structs (no UnmarshalJSON/Validate methods). The loader must validate required fields itself: non-empty language/version/image/entrypoint, non-empty run argv, and all six defaultLimits values >= 1.
