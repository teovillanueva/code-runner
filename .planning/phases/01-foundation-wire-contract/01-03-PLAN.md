<objective>
Prove the Phase 1 foundation works end-to-end at boot. Build a minimal Go worker entrypoint (apps/worker/main.go) that loads all manifests from the languages/ directory, prints the available languages, and constructs the stub Runner + StdinTransport so the swap seams are proven to compile into the binary. Add a shared TypeScript manifest loader in packages/contract that reuses the generated ManifestSchema, so the future Hono API (Phase 3) lists and resolves languages with no hardcoded language identifiers — satisfying LANG-03's "no languages hardcoded in Go OR the API" by construction.

Purpose: This is the "drop a folder = a new language" demonstration for Phase 1: the binary discovers python from its manifest at boot with zero language code changes. It also closes the API-side half of LANG-03 without building Phase 3 endpoints.

Output: apps/worker/main.go (+ test), packages/contract/src/manifest.ts (+ test), updated packages/contract/src/index.ts re-export.
</objective>
