<interfaces>
StdinTransport (internal/stdintransport/transport.go) — implement a Redis-backed type satisfying:
```go
type StdinTransport interface {
    Publish(ctx context.Context, jobID string, chunk []byte) error
    Subscribe(ctx context.Context, jobID string, handler func(chunk []byte)) (Subscription, error)
}
type Subscription interface { Close() error }
```
Relevant wire types (packages/contract/gen/go/wire):
```go
type StdinMessage struct { Chunk string `json:"chunk"` }
type ControlMessage struct { Type ControlType `json:"type"` }   // "start" | "kill" | "stdin_close"
type JobSpec struct { JobId, Channel, Language, Version, Image, Entrypoint string; Run []string; Compile *JobSpecCompile; Limits Limits; Files []FileInput; Interactive bool; EnqueuedAtMs int }
type JobStatus struct { JobId, Channel, Language, Version string; State JobState; UpdatedAtMs int }
```
</interfaces>
