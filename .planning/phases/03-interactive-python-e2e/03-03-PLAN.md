unbuffered env is the LOCKED requirement; the manifest run command `python main.py` will then stream).

MUST NOT require root to read /workspace). WORKDIR /workspace. Do NOT set a CMD/ENTRYPOINT that runs
code — the runner supplies the run argv (`python main.py`) from the manifest. Add a .dockerignore so
the build context stays minimal.
